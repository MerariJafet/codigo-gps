# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1] - 2025-12-30

### Added
- **GitHub Actions CI**: Automated pipeline for frontend (lint/build) and backend (pytest).
- **Benchmark Methodology**: Added `docs/BENCHMARKS.md` and `scripts/benchmark_graph.py` to measure performance.
- **CI Badge**: Visual indicator of build status in README.

### Fixed
- **Mermaid Diagram**: Fixed syntax errors in architecture visualization for better GitHub rendering.
- **Requirements**: Added missing `python-multipart` to backend dependencies.

### Changed
- Improved README structure with new "Performance & Limits" section.

## [0.1.0] - 2025-12-30

### Added
- Initial public release (MVP).
- 3D Hologram interactive visualization.
- FastAPI backend with NetworkX analysis.
- Next.js frontend with Three.js.
- Docker Compose support.
